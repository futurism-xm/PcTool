# PcTool

一个基于 C++ / Win32 的 Windows 桌面工具，集成性能监控、截图与长截图、GIF 录制、屏幕录制、中英翻译、剪切板历史和 7-Zip 压缩解压。

通过任务栏或系统托盘访问常用功能，也可以在快捷键管理中设置自己的操作习惯。

## 功能

| 功能 | 说明 |
| --- | --- |
| 性能监控 | 显示 CPU／GPU 利用率、内存、CPU 频率、上传与下载速度，支持任务栏显示与托盘入口切换 |
| 截图与钉图 | 窗口识别、选区截图、画笔、形状、箭头、文字、马赛克等标注，支持钉图、复制与保存 |
| 长截图 | 手动双向滚动拼接、单击自动向下截取，支持整个选区或选区内单个竖向滚动区域 |
| GIF 录制 | 1～30 FPS、倒计时、暂停、标注、光标与激光指示，结束后循环预览 |
| 屏幕录制 | MP4 输出，支持系统声音、麦克风、暂停、标注、光标与激光指示 |
| 离线文字识别 | 使用 PaddleOCR 模型和 ONNX Runtime 在本机识别截图文字 |
| 中英翻译 | 输入、截图、划词三种入口，支持多个翻译源及独立结果展示 |
| 剪切板历史 | 查看本次运行期间的文本记录，快速选择和复制 |
| 7-Zip | 集成文件管理器、压缩与解压及资源管理器右键菜单 |

长截图通过图像匹配拼接，动态布局、重复图案或重叠不足时可能暂停；目前不支持横向或多个列表同时拼接。GIF 最多使用 256 色，高 DPI 下会按屏幕缩放比例降低输出分辨率，以减小文件体积。

截图翻译和文字识别按需加载本地 OCR 模型，识别结束后释放模型会话及推理缓存，避免大图识别后持续占用大量内存；识别期间的内存峰值仍随图片内容和大小变化。

划词翻译支持来源应用通过子进程写入剪贴板，按本次请求的来源进程、创建时间和会话校验。若复制内容没有所属窗口，则在本次 Ctrl+C 已发送、剪贴板产生新内容、来源仍在前台且请求未取消时接收文字，不再因缺少所属窗口而拒绝填入。明确属于无关进程的内容仍拒绝接收。用户编辑、重新取词或关闭窗口后，旧结果不能覆盖当前输入；启用翻译源后，取词成功会自动提交翻译。

划词翻译会先等待快捷键释放，再向来源窗口发送 Ctrl+C；等待期间显示“正在复制所选文字…”。复制投递后等待文字的超时为 1.5 秒，来源程序先发布空内容或图片格式时会继续等待后续文字，不会立即判为空。若来源程序以管理员身份运行，Windows 可能阻止普通权限取词，界面会说明原因；可以手动复制后粘贴翻译，程序不会自动提权。

`Alt+E` 会针对本次取词抑制 Alt 松开时激活来源菜单的副作用；快速松键来不及抑制时，通过 UI Automation 检查来源菜单，确认菜单退出和原编辑焦点后再复制。普通单独按 Alt 的菜单操作保留。

PcTool 日常运行不请求管理员权限；安装和卸载为写入系统菜单及受保护文件，可以请求一次管理员授权。首次运行默认启用当前用户的普通登录自启（HKCU Run），不创建最高权限任务。本次升级会一次性恢复开启，之后保留用户手动关闭的选择。自启按安装路径区分，关闭和卸载只移除本安装拥有的值。支持非 C 盘安装；运行时设置和缓存按用户隔离，程序及依赖保持只读。

GPU 利用率可在性能监控子菜单中单独勾选，显示为 `GPU: 35%`，沿用 CPU 的字体、颜色及每秒刷新。后台读取 Windows GPU Engine 计数器，将各进程在同一物理引擎的占用相加，再显示最繁忙引擎的百分比；多显卡取其中最高值。初次采样或驱动不提供计数器时显示 `GPU: --%`。新配置默认显示，升级保留原来的勾选项，可手动开启 GPU；取消勾选后停止 GPU 查询。

## 安装与使用

系统要求：**Windows 10 2004（19041）及以上的 64 位 Windows，或 Windows 11**。录屏需要可用的图形设备及 Windows 媒体组件，受保护内容可能无法采集。

在本仓库的 **Releases** 页面获取已发布的 `PcTool-<版本>-x64-Setup.exe`，运行安装向导并选择安装位置。安装后创建桌面和开始菜单快捷方式；完整安装包包含 OCR 依赖及 7-Zip，不需要另装 Python 或外部编码器。

截图后可从工具栏进入长截图、文字识别、GIF 或屏幕录制。录制结束后进入预览：点击“完成”复制缓存文件供粘贴，点击下载并选择位置才另存文件。

### 默认快捷键

首次运行默认启用中英翻译和屏幕截图；升级后保留已经保存的开关选择。

| 操作 | 快捷键 |
| --- | --- |
| 输入翻译 | `Alt+Q` |
| 截图翻译 | `Alt+W` |
| 划词翻译 | `Alt+E` |
| 屏幕截图 | `Ctrl+Alt+A` |
| 剪切板历史 | `Alt+C` |

以上组合可以修改或清空。任务管理器、画图、7-Zip 和快捷键管理也支持绑定，默认未绑定。快捷键与其他软件冲突时，请在快捷键管理中调整。

任务栏及托盘功能菜单按“任务管理器 → 远程连接 → PowerShell”排列。“远程连接”打开 Windows 自带的远程桌面连接窗口（mstsc），由用户填写目标后连接；PowerShell 入口以管理员身份打开 Windows PowerShell，如系统弹出 UAC 提示，确认后启动，取消则不打开。
“快捷键管理”中也可以为远程连接设置全局快捷键，默认不绑定；保存后任务栏菜单会同步显示绑定组合。

### 配置翻译源

从“中英翻译”的子菜单打开“翻译源设置”，添加服务、填写参数并验证。当前支持：

| 服务 | 所需配置 |
| --- | --- |
| OpenAI 兼容接口 | API 基础地址、API Key、模型名称 |
| DeepL | Free / Pro 类型、API Key |
| 微软 Azure Translator | 订阅密钥、区域 |
| 百度通用翻译 | App ID、密钥 |

PcTool 不提供内置公共密钥或免费翻译额度，费用及可用性由所选服务决定。翻译会将提交的文字发送至配置的服务；**离线 OCR 不等于离线翻译**。含汉字的文本默认译为英语，其他文本译为简体中文。

### 数据与卸载

应用管理的配置与缓存位于安装目录；翻译源直接放在 `Data/Translation`，其他设置和缓存按 Windows 用户隔离：

```text
PcTool 安装目录/
├── PcTool.exe
├── Uninstall.exe
├── Data/Translation/    # 可复制到其他电脑的翻译源 sources.json
├── Data/<用户 SID>/     # 当前用户的功能设置、快捷键及 7-Zip 设置
└── Cache/<用户 SID>/<YYYY-MM-DD>/ # 当前用户的截图、GIF、录屏及临时文件
```

**迁移翻译源：** 退出新旧电脑上的 PcTool，将旧电脑的 `Data/Translation` 文件夹复制到新电脑安装目录的 `Data` 下，覆盖同名文件夹，再启动 PcTool。源顺序、启用状态、地址、模型及密钥一并保留，无需重新验证；服务本身的密钥有效期、余额和网络限制仍适用。复制会替换目标已有翻译源，不自动合并；覆盖前可自行备份。

翻译源使用可移植的 v2 JSON，**其中密钥可直接读取**，不绑定电脑、用户 SID 或 Windows DPAPI。同一安装的本地用户共享这份翻译源；其他支持此格式的 PcTool 安装也能读取复制后的文件。请勿公开、提交或发给不可信的人，不同软件的翻译配置格式不保证兼容。

仅支持 `Data/Translation` 中的可移植 v2 配置，不读取旧 SID 目录，也不解密或转换旧版 v1 配置。首次使用需要配置翻译源，之后可直接复制新文件夹；误放旧版文件时会提示版本不受支持，不覆盖原件。

升级时将除 `Data/Translation` 以外的旧平铺数据和缓存迁移至实际交互用户的 SID 目录，验证文件内容一致后才删除原件。已有 SID 目录继续使用；同名内容冲突时停止迁移并保留原件。Data／Cache 根目录允许普通用户创建自己的私有目录；仅 `Data/Translation` 允许本地用户共享读写，程序和依赖仍保持只读。提权授权所用的管理员账户不会替代实际交互用户。

截图“完成”同时提供图片和 PNG 文件剪贴板格式；GIF、MP4 的“完成”复制缓存文件。自 v0.1.2 起，缓存按本地日期分文件夹，内部按 `Screenshots`、`Gif`、`Recordings` 和 `SevenZip` 分类。每次启动只清理日期距当天超过 7 天的缓存，恰好 7 天、当天和未来日期的文件夹保留；运行中不会定时清理。

清理保留当前剪贴板引用、正在使用或无法删除的文件，对应日期文件夹在清空后才删除；剪贴板暂时无法读取时跳过本次清理，下次启动重试。迁移后的旧版未分日期缓存按文件修改日期使用相同的 7 天规则。系统剪贴板历史中的旧文件引用不保证长期有效。主动另存的文件位于用户选择的位置，不受缓存清理影响。

使用安装目录内的 `Uninstall.exe` 卸载。确认后先停止本次安装的全部任务，包括录屏、GIF、翻译和内置 7-Zip；任务未响应时会强制结束，确认进程实际退出后才删除文件，未完成结果可能不可用。卸载期间不能重新启动这些功能。

卸载清理受管文件、数据、快捷方式和本次安装的右键菜单等系统注册；如果之前独立安装过 7-Zip，则恢复其注册。不关闭或重启资源管理器，不终止无关程序。已加载的兼容 7-Zip 扩展无法直接删除时，会将经过文件身份核对的受管残留迁至同盘受保护的 `.PcToolCleanup/PcTool`，清空原安装目录；仍有无关文件、未知旧版扩展或目录无法迁移时保留原处并说明。临时 Windows 计划任务在占用释放后清理磁盘文件：立即尝试，之后每五分钟及登录时重试；无需重启电脑，无可见窗口或常驻服务。用户自行放入的无关文件和主动另存的文件不在清理范围内。不要用直接删除文件夹代替卸载。

内置 7-Zip 设置读取或写入结束后即释放 hive；卸载先恢复或移除本安装拥有的菜单注册，再通知系统刷新。缓存的菜单与命令对象也会检查卸载状态；卸载完成后重新打开菜单不再出现 PcTool 提供的 7-Zip。已有用户级 7-Zip 配置保留。后台清理成功前保留卸载标记，保护已加载的旧版扩展；已展开的旧菜单无需强制关闭。清理记录和脚本位于仅管理员及 SYSTEM 可修改的 ProgramData/PcTool/CleanupJobs，按安装实例及文件身份核对后删除受管文件和空目录，全部完成后移除标记、任务和记录。任务登记或实际删除失败会明确报错并保留重试入口。

安装、卸载和后台清理共用目录互斥锁。同一目录重新安装前，安装器会撤销仍指向原目录的旧清理任务，并更换安装实例标识，防止后台任务误删新文件；已迁出的残留由独立文件身份保护，继续清理且不操作重装目录。同时兼容撤销旧版卸载针对本次受管文件、目录及 Data／Cache 的重启删除记录。其他软件和无关文件的记录保留。如有待执行的重命名会影响新安装，安装器会提示先重启再安装。升级中被占用的旧 DLL 改名后使用同一后台机制清理。7-Zip 两种位数的右键扩展缺失或菜单注册写入／读回验证失败时，不报告安装成功；注册失败会回滚本次注册改动。

## 从源码构建

需要 Windows、带 C++ 桌面开发工作负载及 Windows SDK 的 Visual Studio、CMake，以及 PowerShell。当前预设使用 **Visual Studio 2026（Visual Studio 18 2026 生成器）**；CMake 必须支持该生成器。请在 Visual Studio 的 **x64 Developer PowerShell** 中执行以下命令。

首次准备依赖需要联网，脚本会校验固定版本 OCR 下载文件的 SHA256。7-Zip 使用仓库内的源码构建，不需要 `Reference` 目录。

```powershell
# 在仓库根目录执行
powershell -ExecutionPolicy Bypass -File scripts/setup-ocr.ps1
powershell -ExecutionPolicy Bypass -File scripts/build-7zip.ps1
powershell -ExecutionPolicy Bypass -File scripts/setup-package-tools.ps1

cmake --preset vs2026-x64
cmake --build --preset vs2026-x64-debug
cmake --build --preset vs2026-x64-release
```

主程序输出为 `out/build/vs2026-x64/Release/PcTool.exe`。运行时需保留同目录下部署的模型、运行库和模块，不能只复制主程序 EXE。

### 测试与安装包

```powershell
ctest --test-dir out/build/vs2026-x64 -C Debug --output-on-failure
ctest --test-dir out/build/vs2026-x64 -C Release --output-on-failure

powershell -ExecutionPolicy Bypass -File scripts/build-installer.ps1 -BuildDirectory out/build/vs2026-x64
```

安装包输出到 `out/installer/`，文件名包含 UTC 构建时间和源码指纹；旁边的 `.sha256` 与 `.metadata.json` 记录安装包和组件哈希。脚本从全新暂存目录打包并重建主程序、卸载辅助程序；`-SkipDependencyBuild` 仅在 7-Zip 来源指纹与全部二进制校验通过时允许复用。构建产物通过 GitHub Releases 分发，不提交到源码仓库。

桌面集成测试可在配置时增加 `-DPCTOOL_ENABLE_DESKTOP_TESTS=ON`；需要可交互、未锁定的 Windows 桌面及相应音视频设备。部分开发评估脚本需要额外测试数据或运行环境，不属于普通构建前置条件。

### 目录结构

```text
src/          应用与各功能模块源码
Resources/    程序图标等构建资源
cmake/        模块清单与安装规则
scripts/      依赖准备、构建与打包脚本
packaging/    安装器与组件说明
third_party/  7-Zip 源码、OCR 依赖说明及许可证
tests/        原生测试、测试夹具与验证记录
docs/         架构与资源说明
```

架构说明见 [ARCHITECTURE.md](docs/ARCHITECTURE.md)，OCR 依赖见 [third_party/ocr/README.md](third_party/ocr/README.md)。
