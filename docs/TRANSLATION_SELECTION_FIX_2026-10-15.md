## 已确认问题与处理

| 程度 | 位置与触发条件 | 影响、证据与修复 |
| --- | --- | --- |
| P2 | `src/translation/translation_controller.cpp`：启动取词及收到不含文字的剪贴板中间态 | 原代码在 Ctrl+C 尚未完成时就显示“识别内容为空”；先发布空内容／图片、再写入 Unicode 文字的来源会提前结束请求。新增分阶段跨进程回归在旧代码上失败。现在先显示复制进度，保留监听并轮询；文字到达即填入并提交，未就绪时继续等待。 |
| P2 | 同文件的 `StartCopy`／`Tick`：快捷键一直按住、来源无响应或剪贴板持续占用 | 原来的按键等待与无响应复制缺少完整结束条件，部分读取分支还会延长期限。现在按键等待及复制结果各有固定的 1.5 秒期限，区分松键提示、读取失败与最终为空。保留来源校验、用户编辑／关闭／新输入取消及旧结果不能覆盖输入的保护。 |
| P2 | `packaging/cleanup-jobs.ps1`：从 PowerShell 7 启动安装器 | 隔离安装首轮返回 1。保留子进程输出后确认 Windows PowerShell 继承了不兼容的模块搜索路径，`Set-Acl` 无法自动加载。现在 Desktop 版明确从自身 `$PSHOME` 导入系统安全模块；不修改用户全局环境。相同 PowerShell 7 启动场景的最终包回归通过。 |
| 测试问题 | `tests/cleanup_jobs_tests.ps1`：在首个任务退出前释放文件占用 | 任务可能完成清理并删除自身，使测试随后查询任务时报不存在。已改为保持占用，先确认首轮退出且返回待重试，再释放并重试；未放宽清理结果断言。 |
