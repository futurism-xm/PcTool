# 普通权限运行与安装卸载重构（2026-10-19）

本报告覆盖本轮重构；`INSTALLER_OPTIONAL_STARTUP_2026-10-19.md` 记录的管理员自启降级方案已被本轮替代。本轮不提交、不发布远程仓库。

## 已完成的行为

- 主程序使用 `asInvoker`。安装与卸载仍申请管理员授权；日常运行和登录自启不提权，支持非 C 盘安装。
- 自启使用当前用户的 `HKCU Run`，命令为完整路径加 `--background`，按安装路径区分并读回验证。首次正常运行及本次升级恢复开启，保存 `StartupSchema=2` 后尊重用户关闭；保存或注册失败明确报告。
- Data、Cache 在安装目录按用户 SID 隔离。程序及依赖只读，各用户只能写自己的私有目录。迁移旧设置、7-Zip 私有 hive 和缓存时逐文件校验 SHA256，再删除源文件；内容冲突保留原件并报错。生产迁移使用桌面 Shell 用户身份。
- 保留桌面、开始菜单快捷方式和 x86/x64 完整动态 7-Zip 菜单；保留独立 7-Zip 恢复、注册读回和回滚、用户覆盖保护。
- 卸载先设置状态、撤销本安装自启、停止本安装的 PcTool/7z/7zG/7zFM。通过规范化路径和进程句柄复核身份，统一等待两秒后终止仍未退出的本安装进程；录屏等进程内任务随所属进程结束。
- 不终止或重启 Explorer，不终止外部 DLL 宿主和其他路径的同名进程，不新增重启删除队列。外部占用使用受保护的临时任务重试清理，保留卸载标记直到扩展清理完成；重装取消旧任务并更换实例。
- 清理旧高权限任务、明确属于本安装的各用户 Run 注册；离线 hive 使用私有 `RegLoadAppKey` 句柄并释放。
- 普通权限向管理员来源取词时提示 Windows 权限隔离及手动复制方案。
