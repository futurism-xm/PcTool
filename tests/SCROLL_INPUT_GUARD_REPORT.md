# 长截图输入保护与减速

日期：2026-09-12。本报告是双向长截图的后续修正。

## 修改

- 旧逻辑拦截左／右键与纵向滚轮，但鼠标移动、中键及侧键仍可能到达原页面，触发悬停展开或导航。
- 增加覆盖选区、不激活的鼠标输入保护层。采用可命中的最低非零透明度，并设置 `WDA_EXCLUDEFROMCAPTURE`，避免透明像素被 Windows 当作鼠标穿透。正常鼠标移动仍可见，原页面不再接收选区中的鼠标移入、点击和拖动消息。
- 原页面只接收控制器定向投递的纵向滚轮。左键只控制长截图自动滚动，右键和 Esc 取消；中键、侧键与横向滚轮被消费。工具栏位于保护层上方，保持正常命中。
- 透过保护层按窗口层级和命中区域确定来源，排除本会话窗口，继续校验来源身份与前台状态；不通过临时隐藏保护层找来源，也不默认向无关前台应用投递。
- 最小投递间隔从 150 ms 改为 350 ms，包含为整格控件补发的滚轮；画面稳定等待从 120 ms 改为 200 ms。自适应位移目标从正文约三分之一改为五分之一，小步控件单次通常不超过 60 个滚轮单位，首次探测为 30 单位；仅支持整格的控件仍会补足 120 单位。高速输入继续合并，不积压长队列。
- 完成、取消或销毁会话时撤销保护层，恢复原窗口输入。

## 验证

- 使用独立原生窗口及真实鼠标输入，检查选区内固定区域和列表区域的实际鼠标命中：保护层接收输入，源窗口的 `WM_MOUSEMOVE`、中键及侧键计数不增加，实际光标位置继续跟随移动，源窗口前台焦点不变。
- 纵向滚轮仍到达真实子列表，验证上下逐像素拼接、回访不增高、自动续接与暂停。结束后源窗口重新收到鼠标移动，保护窗口已销毁。
- 突发滚轮合并且停止后不继续回放；核对实际来源滚轮记录中手动、自动及补发投递间隔不少于 350 ms（断言保留 5 ms 采样容差）。来源同时记录系统消息队列时间 `GetMessageTime` 和绘制后的回调时间，间隔断言使用前者；实际正文位移和成图仍单独校验。正常小步滚动位移不超过测试正文五分之一。
- Debug 首轮相关 CTest 6/6 通过，含核心、双向长截图、QQ 风格长截图、实时采集、会话和模块边界：`out/scroll-input-debug-tests.log`。QQ 风格测试包含全屏工具栏、编辑、PNG 文件与图片复制、下载取消／重试、右键及 Esc 退出。
- Release 核心 CTest 2/2 通过：`out/scroll-input-release-core.log`。
- 最终来源定位修正后的 Debug 原生全场景通过：`out/scroll-input-debug-final.log`。
- Release 首轮计时间隔断言出现 343／344 ms，使用的是源窗口绘制后回调时刻，包含队列调度差异。失败证据保留为 `out/scroll-input-receive-timing-failure.log`、`.csv`；测试改用系统消息入队时间断言投递节奏，没有修改程序的 350 ms 限制或放宽速度要求。
- 最终 Release 双向长截图、QQ 风格长截图及会话回归全部通过：`out/scroll-input-release-bidirectional-scroll-test.log`、`out/scroll-input-release-qq-long-test.log`、`out/scroll-input-release-session-test.log`。已检查原生测试的选区／工具栏实际画面；测试背景中的其他应用不计作网页交互实测。
- Debug、Release 构建成功，日志为 `out/scroll-input-debug-build.log`、`out/scroll-input-release-build.log`。已启动默认 `cmake-build-release/PcTool.exe`，进程和文件哈希记录于 `out/scroll-input-launch.log`；启动期间保护现有缓存，用户参考录屏哈希保持一致。
- 安装包路径为 `out/installer/PcTool-0.1.0-x64-Setup.exe`；重建及最终清单核对结果分别记录于 `out/scroll-input-package.log`、`out/scroll-input-package-verification.log`，安装包不包含运行配置、缓存或参考录屏。

## 环境限制

本轮使用独立原生测试窗口；没有在用户遇到悬停展开的具体网页上实测。三档 DPI 为消息模拟，未在真实混合 DPI 硬件复测。保护针对标准窗口鼠标消息；应用自行轮询全局光标、定时刷新、键盘输入或网络内容变化仍可能改变布局，原有可靠匹配失败暂停机制继续保留。
