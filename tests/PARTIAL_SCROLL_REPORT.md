# 局部滚动长截图与底部提示验证

日期：2026-09-11。

## 改动

- `ScrollStitcher` 使用独立窄分块匹配、鼠标邻近投票与滚动区域识别，再以正文条带合成全宽输出。移除全选区平均变化量作为采集门槛，锁定后仅在目标区判断变化。
- 固定顶部与原始可见正文保留一次，新增正文插入原视口底部，固定底部移到末尾。两侧估计背景色延展；连续边界保留，非均匀列中的大图标／文字不拉长。
- 相邻区域同位移时依据鼠标与固定分隔识别一个目标。重复图案歧义、倒滚、重叠不足、目标改变或不可对应布局不追加，保留已有内容。
- 手动与自动滚轮共用事件编号、方向、位置、时间、来源窗口及进程身份记录。来源移动、失焦和关闭停止追加，不当作到底。
- 两次无效向下滚动，跨度至少 600 ms、最后事件后至少 300 ms 且画面稳定，显示三秒居中提示。自动滚动停止；提示消失不关闭会话，有新内容时恢复追加。没有滚轮事件不会因停手报到底。
- 首帧在覆盖层创建前取得，避免把覆盖层初始化过渡误认为原始页面。编辑、预览、复制和保存共享同一成图，页脚标注按新增高度映射。

## 自动化与桌面用例

核心像素测试采用 900×740 整体选区、180×200 内部视口：滚动宽度仅 20%，顶部固定区域超过四分之一高度。逐像素检查正文、全宽尺寸、固定顶部／底部、侧边背景、大图标仅一份；覆盖反向恢复、另一个列表、布局缩短、外部动画、周期图案歧义、无重叠和全宽容量计算。底部状态机独立检查事件数、600/300 ms 边界、停手、重复提示与延迟内容。

`partial-scroll-test` 使用独立原生窗口和真实 SendInput 滚轮，验证：小视口连续追加、每步 6 像素的定时平滑滚动、手动／自动到底、停止滚轮不提示、提示自动消失后会话保留、没有新滚轮事件的延迟内容到达后继续、切换区域、倒滚恢复、来源移动／失焦／关闭和首次已到底。完成后的整个图像逐像素比较，覆盖层与提示没有进入结果。

96／144／192 DPI 消息模拟分别生成桌面截图，并验证提示区域确实存在深色像素。测试取桌面截图时临时取消测试窗口的采集排除；不在该短暂期间派发 UI 消息，防止测试动作本身触发采集变化并先隐藏提示。正常应用始终保持排除。三种截图已人工查看，提示居中、文字完整；这不是三台不同 DPI 显示器的实测。

## 浏览器对照

通过浏览器工具在独立 Chromium 页面 `tests/fixtures/partial-scroll.html` 操作内部滚动容器，使用合成中文／英文／数字记录，不操作用户页面。保留固定页头、侧栏、筛选表头和页脚，按按钮各滚动 72 像素。

浏览器工具返回的截图实际为经过重采样的 JPEG（虽然保存名为 `.png`），初版变化边界受压缩噪声影响落在 y=336～584，含固定边框，肉眼出现截断行。修正后识别为 y=341～579，每次位移 72。添加已知 HTML 视口边界断言，并通过页面上的独立按钮展开全部正文，对成图每八行与独立完整正文比较，防止仅校验算法自身裁切条带而漏掉接缝。

浏览器测试包含真实排版、实际容器滚动、帧匹配与全宽成图；未将其宣称为用户浏览器窗口的 DXGI／滚轮钩子端到端测试。浏览器 JPEG 对照允许每通道平均误差 8，原生与核心合成图仍逐像素比较。

## 限制及未实测项目

- 未在真实多显示器、负坐标跨屏和混合 DPI 硬件重新实测。
- 未穷举所有浏览器的平滑滚动、无限列表、虚拟化表格和持续动画；不可靠的匹配会暂停。图片背景和复杂渐变的侧边延展不保证无缝。
- 同一会话支持一个竖向区域；两个没有可辨识边界、内容又相似的并列区域存在图像歧义，不承诺同时拼接。
- 未在另一台隔离电脑重新执行安装／卸载。本轮不改安装结构。
- 用户参考录屏原文件及 `out/qq-long-reference/qq-reference.mp4` 副本保留，不加入安装包。
