# GPU 利用率监控

日期：2026-09-20；版本：0.1.2。

- 性能监控子菜单在 CPU 利用率后加入 GPU 利用率；复用勾选、任务栏／托盘菜单、字体颜色、百分比格式和稳定列宽。新配置默认开启，旧配置保留原显示位掩码，GPU 使用新增位，不复用原项目。
- 后台线程每秒读取英文 GPU Engine PDH 计数器，按显卡 LUID、物理 GPU 和引擎合计各进程占用，再取最繁忙引擎，限定 0～100%。首次或不可用时显示 `GPU: --%`，与有效 0% 区分。支持动态进程实例，限制读取缓冲区和重试次数。
- 取消 GPU 勾选或销毁任务栏监控窗口后停止查询，返回任务栏显示时按设置恢复；错误初始化采用 30 秒重试间隔。UI 读取原子快照，不同步等待 PDH 查询。

## 验证

- Debug、Release 构建及 `gpu_monitor` CTest 通过。测试包含多进程共用引擎、多引擎／多显卡、100% 上限、无效／非有限／空样本、有效空闲、连续开关和退出资源释放。
- 本机真实 PDH 查询成功，首轮记录为 0.301583%；未用模拟值代替实际采样。
- 隐藏原生任务栏夹具覆盖六项全部 63 种非空组合，以及 100%、150%、200% 模拟 DPI、托盘宽度变化、文字完整性和稳定窗口边界，通过。
- 独立目录运行存储测试，GPU 开关保存、重载通过；旧设置布局测试中的注册表持久化分支不运行，持久化验证由当前文件存储测试承担。
- 安装包通过 Release 打包脚本重建。本轮未安装替换用户运行中的版本。

未实测：真实混合 DPI 屏幕、不同厂商／多显卡硬件，以及与任务管理器同一时刻逐项数值对照。不同采样窗口可能导致两者数字略有差异。未执行依赖用户桌面点击的完整菜单自动化。
