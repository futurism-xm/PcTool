# 截图／钉图交互验证记录

日期：2026-09-08。测试入口为项目原生 `PcToolCaptureIntegration`，使用独立网格背景及测试钉图，不操作用户钉图。

## 修复

1. 拖动钉图功能栏不再将编辑窗口区域扩大至整个虚拟桌面。移动中区域始终为图片、当前功能栏、可见设置面板及字号列表的并集，旧位置由底层桌面重新显示。
2. Esc、取消模式及捕获丢失结束当前指针操作并重绘；未提交笔画被丢弃，已经移动的内容保留当前位置，不新增移动历史。
3. 输入中的序号标注在拖动中断后重新显示文本输入框，保留未提交文字。

### 不适用与未执行

- 普通截图／钉图的马赛克不提供单独移动；本轮验证添加与输出，不新增移动功能。
- 普通截图的撤销为删除最后一项，不提供独立移动撤销历史；长图编辑器有移动历史，已验证两次撤销分别撤回移动和添加。
- 普通文本输入框内部拖动用于选择文字；输入中拖动标注位置测试针对现有序号工具，普通文本在提交后测试移动。
- 本机检测到一块显示器：真实副屏负坐标、跨屏及混合 DPI **未执行**。三档 DPI 测试通过修改布局 DPI 实现。
- 中文和多行文字已测试，也发送了 IME 开始／结束消息；真实输入法候选窗、候选选择与组合输入 **未执行**，不将合成消息当作真实输入法验收。
- 文件保存测试使用完整渲染输出直接写入 PNG；本轮未自动操作系统 PNG 另存为对话框及模拟磁盘写入失败。

## 运行和证据

```powershell
PcToolCaptureIntegration.exe pin-interaction-test D:/temp/pin-interactions
PcToolCaptureIntegration.exe editor-test D:/temp/editor
```

开启 `PCTOOL_ENABLE_DESKTOP_TESTS` 后，钉图矩阵注册为 `capture_pin_interactions`，桌面测试串行运行。测试必须在解锁桌面执行，运行中不同时操作鼠标。

- 逐项运行结果：输出前缀加 `.txt`，其中包含系统显示器数量和环境说明。
- 画面证据：前缀加 `-96/-144/-192-drag-start/mid/end.png`；原图完整输出为 `-annotations.png`。
- Debug 构建和钉图矩阵、长图编辑测试已通过；Release 及最终回归结果见本报告末尾的交付结果。

## 交付结果

- Debug、默认 Release 构建通过，无新增编译警告。
- Debug 相关 CTest：13/13 通过。包括钉图矩阵、长图编辑、拼接采集、OCR 引擎／结果窗口／截图入口、录屏样式／光标／标注／预览及核心绘制测试。
- Release 默认 CTest：7/7 通过；另行执行 Release 原生钉图矩阵和长图编辑测试，均通过。
- 每档 DPI 执行空内容 6 次、单个标注 6 次、混合标注 30 次功能栏拖动，三档合计 126 次；混合标注分支覆盖正常释放、Esc、捕获丢失和取消模式。
- 默认 Release 证据在 `cmake-build-release/pin-interactions.txt`、`pin-interactions-*-drag-*.png`；原生运行日志在 `out/build/pin-release-native.log`。测试生成文件只用于验证。
- 上表未执行项仍保持未执行，不将模拟环境或其他测试结果代替实测。
