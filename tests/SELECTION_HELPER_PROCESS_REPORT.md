# 划词复制来源兼容性

日期：2026-09-22；版本：0.1.2。

用户反馈微信消息已选中却提示“剪贴板内容来自其他程序”。旧实现直接比较剪贴板所属 PID 和来源窗口 PID；主窗口与复制辅助进程 PID 不同时会必然误拒绝。当前机器存在 WeChat.exe 及多个子进程，但未获得用户当次失败的所属 PID 日志，不能把这一兼容性缺陷等同于已确认的微信截图根因。

## 第一轮修改（辅助进程）

- 每次请求绑定来源进程句柄，接受来源本进程或经 Toolhelp 父子链验证的存活子进程。逐级检查会话、创建时间及存活状态，防止 PID 复用、循环或失效父进程导致误接受；最多 32 级。
- 祖先进程、兄弟应用、未知 PID 和来源退出均不放行；不按文件名／目录盲目信任。无法确定剪贴板所属进程时，改用“无法确认来源”的提示，不断言来自其他程序。
- 原请求编号、用户输入序号、前台窗口、剪贴板序列号校验继续有效。完成或取消关闭来源句柄，结束监听，迟到结果不得覆盖编辑内容。
- 复制仍立即弹窗，等待按键释放后发送 Ctrl+C；没有加入固定判空延迟，也没有移除来源校验。

## 验证

- Release / Debug PcTool 与翻译测试构建通过；两种构建的独立多进程场景连续 12 次取词成功：实际子进程通过独立 message-only 窗口写入剪贴板，文字完整、警告清除、窗口立即显示、仅一次本地测试源提交。
- 验证同进程、辅助进程可接受，未知／祖先写入拒绝；无关剪贴板及后续迟到结果不能覆盖输入，来源关闭及请求取消后拒绝旧写入。
- translation_core CTest 通过。
- 独立 Notepad++ 合成文档回归通过：12 次选区复制、3 次改键、10 次浮窗重复调用、10 次关闭全局快捷键后的菜单入口和来源关闭提示。首次默认 Alt+E 测试与当前运行 PcTool 冲突，未收到提交；重跑使用 Alt+F22/F23 等专用测试组合，未改变用户安装的配置。
- 日志：`out/selection-helper-test.log`、`out/selection-helper-debug-test.log`、`out/selection-helper-npp-isolated.log`。测试翻译源完全本地，不调用真实翻译服务。

第一轮未实测：微信原消息的完整 Alt+E 复制链路。computer-use 可读控件树，但截图接口返回不支持接口、点击返回 coordinate input geometry is unavailable，未将模拟程序通过写为微信实测通过。第一轮仍拒绝无所属窗口的剪贴板。

## 第二轮修复（无所属窗口）

用户新截图出现“无法确认复制内容的来源”，且剪贴板历史已有新文字，说明上一轮仅放行辅助进程仍未覆盖无所属窗口的情况。剪贴板文字存在不代表 `GetClipboardOwner()` 一定返回窗口；短生命周期复制窗口销毁后，已呈现的文字仍可读取。

- 无所属窗口时，以当前取词请求关联新内容：必须已发送 Ctrl+C、序列号不同于主动清空后的序列号、来源进程存活、来源窗口仍在前台、输入序号未变化且请求未取消。符合条件直接填入并通过既有流程提交一次。
- 有所属窗口时继续校验来源进程或子进程；明确来自无关进程的文字仍拒绝。没有改为读取历史记录，也没有增加等待弹窗的延迟。
- 无所属窗口无法证明写入进程身份；这是按用户请求采用的上下文兼容判断。极端情况下，无关后台进程恰好在同一等待期间写入无所属窗口的文字，无法通过 Windows 剪贴板接口完全区分。日志仅记录接收事件，不记录正文。
- 独立辅助进程在持有剪贴板期间写入合成中英文文本、销毁临时所属窗口再释放剪贴板，稳定复现无所属窗口。Debug、Release 各通过 12 次普通子进程复制和 12 次无所属窗口复制；检查完整填入、提示消除、提交一次、旧剪贴板不被采用、无关有主进程写入拒绝、用户编辑后迟到的无主内容不覆盖，以及来源退出。
- Debug / Release 构建和 Release `translation_core` 通过。日志：`out/selection-ownerless-test.log`、`out/selection-ownerless-debug-test.log`。
- 独立 Notepad++ 回归通过：12 次选区、3 次改键、10 次重复调用、10 次关闭全局快捷键后的菜单调用及失效来源拒绝；使用隔离测试快捷键，日志 `out/selection-ownerless-npp.log`。
- 截图同时显示“请配置翻译源”：无源时仍填入文字，但不会产生真实译文；自动提交次数使用本地测试源验证，未上传微信消息。
- 微信原消息真实 Alt+E 操作仍未自动化实测；以上为真实 Windows 剪贴板和原生窗口测试，不将其标为微信实测。安装包重建后需安装才能更新当前已安装实例。
