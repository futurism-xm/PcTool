# 长截图首次滚动误报匹配失败

日期：2026-09-12。

## 复现与原因

用户反馈一开始截取就显示“重叠不足或布局无法匹配，已暂停；请缓慢回到已截取位置”。本轮在独立原生窗口复现同样的错误，未操作用户当前文档。

1. 截图选区传入的是进入截图模式时冻结的图像。长截图此前直接用它作为拼接基准；悬停面板在截图期间收起后，实时画面已经不同。测试模拟冻结图像中的面板遮住列表，长截图启动时列表露出，首次实际下滚 15 像素后仍停在原始 740 像素高度并报上述提示。修复前日志及桌面证据保存在 `out/scroll-first-before.log`、`out/scroll-first-before-failure-desktop.png`。
2. 投递滚轮后存在收到尚未滚动的旧帧的时序窗口。此前沿用动作前的稳定计时，在目标外动画发生变化时可能立即尝试匹配并判失败。补充的动画回归复现了这个问题，记录见 `out/scroll-first-animation.log`。

这两项是已复现的程序缺陷。用户本次具体应用／页面尚未提供，不能据此断言其页面只存在这些原因。

## 修复

- 冻结图仅用于启动时的临时缩略预览。输入保护层建立后，使用与后续滚动一致的实时采集流建立首帧基准，再允许发出第一步滚轮。
- 首次实时基准等待初始化和稳定；刚打开时收到的一次滚轮意图保留，不因原有短队列过期而丢失。后续高速滚轮仍合并，不积压回放。
- 初始稳定检查允许以用户指定的滚动位置为中心，避免选区其他区域的动画阻止开始。仍未稳定时明确提示等待初始画面稳定。
- 每次实际滚动从本次动作开始重新计稳定时间；区域尚未锁定时，先检查目标附近是否变化，不拿无关动画作为目标滚动的依据。
- 滚动后不重新设定基准，不吞掉首次新增内容；继续保留真实重叠不足、重复图案、布局改变时的保护暂停。350 ms 最小投递间隔、200 ms 稳定等待及输入保护保持生效。

## 验证

- 原生新增场景：过期截图中的悬停面板消失；打开后立即滚轮（首帧准备前不得投递，准备后不得丢失）；滚动列表旁持续动画。核对来源实际位移、完整新增正文、输出高度和编辑交接。
- 首次悬停面板场景逐像素验证固定区与新增正文；立即滚轮场景逐像素验证没有把已滚动后的画面误作起点；动画场景逐像素验证正文无漏行、重行。
- 增加真实 GDI 光栅文字的核心测试，包含中文、英文、重复行前缀及数字，核对 15／30／60 像素首次位移。
- Debug 双向原生全场景通过：`out/scroll-first-debug-final.log`。覆盖输入保护、鼠标自由移动、退出恢复、双向回访、自动下端续接、反向输入、速度合并、延迟响应、一次／重复边界提示、来源变化和整区拼接。
- Debug／Release 构建日志：`out/scroll-first-debug-build.log`、`out/scroll-first-release-build.log`。Release 核心及模块边界 CTest 2/2 通过：`out/scroll-first-release-core.log`。
- Debug 相关 CTest 5/5 通过（核心、QQ 长截图、实时滚动、会话及模块边界）：`out/scroll-first-debug-ctest.log`。Release 双向原生、QQ 长截图及会话测试全部通过：`out/scroll-first-release-bidirectional-scroll-test.log`、`out/scroll-first-release-qq-long-test.log`、`out/scroll-first-release-session-test.log`。包含编辑、保存取消／重试、PNG 文件及图片复制、退出清理回归。
- 已启动默认 Release 新版，进程及哈希见 `out/scroll-first-launch.log`；启动时保护已有缓存，参考录屏哈希保持不变。安装包为 `out/installer/PcTool-0.1.0-x64-Setup.exe`，构建及清单核对记录见 `out/scroll-first-package.log`、`out/scroll-first-package-verification.log`。包内不携带用户配置、缓存和录屏。

## 未实测与限制

未在用户此次报错的具体页面实测。100%、150%、200% DPI 为原生消息模拟，真实混合 DPI 未实测。输入保护针对标准鼠标消息，页面自行轮询光标、网络刷新或键盘操作仍可能改变布局；真实内容无可靠重叠时继续暂停，不强行拼接。
